# 邮件助手：批量独立发送邮件

同一份正文、同一批抄送人，**给每个收件人各发一封独立邮件**（收件人之间互相看不到），自动附带签名和附件。
适合给多家供应商发统一询价这类“内容一样、收件人不同”的场景，减少重复操作和复制粘贴出错。

---

## 快速开始

1. 安装 Python 3.11 及以上；如需导入 `.xlsx` 名单，再运行一次：
   ```bash
   pip install openpyxl
   ```
2. 双击 **`邮件助手.pyw`**，浏览器会自动打开界面（不会出现命令行窗口）。
3. 第一次使用：在 **账号设置** 登录发件邮箱 → 在 **签名** 填好签名 → 去 **写邮件**。

> - 再次双击不会重复启动，只会重新打开页面。
> - 用完点右上角 **“退出”**。忘了也没关系：所有页面关闭约 5 分钟后会自动退出（正在发送时不会退出）。

## 四大功能

### 1. 写邮件

| 区域 | 说明 |
|---|---|
| **① 收件人** | 一行 = 一封独立邮件。可直接填写、**从 Excel 复制多行粘贴**、导入 Excel/CSV，或 **从名单添加**。一格里填多个邮箱（用 `;` 分隔）表示这几个人收到同一封。其他列（公司、联系人…）可作为变量。 |
| **② 邮件内容** | 抄送 / 密送（每封都相同），右侧 **“组合 ▾”** 一键加入常用邮箱组合。**通用变量**：项目名称、项目代号、采购物资等本次所有邮件相同的内容。主题和正文中输入 `{{` 会弹出变量提示（绿色＝通用变量，蓝色＝收件人表格的列）。 |
| **③ 附件** | 拖入或点击选择；所有邮件附带相同附件，总大小建议不超过 20MB。 |
| **底部操作栏** | 载入 / 存为模板、新建空白；**预览**（逐封查看）、**发一封给自己测试**、**发送**。 |

- 编辑内容会**自动保存**为草稿，关闭后再打开不会丢失。
- 用到了未定义或未填写的变量，正文下方会实时提醒。

### 2. 资料管理

集中管理保存过的资料（模板、名单、组合可查看、编辑、重命名、删除，删除需点两次确认），查看发送记录，以及备份与恢复：

- **邮件模板**：整封邮件（主题、正文、收件人、抄送、通用变量、附件）。可“用此模板写邮件”。修改模板 = 载入后编辑，再以同名“存为模板”覆盖。
- **收件人名单**：常用供应商名单。可新建、从 Excel/CSV 导入为新名单、直接编辑表格、一键加入当前邮件。
- **抄送/密送组合**：常用的几个邮箱（如领导＋技术＋财务）。
- **发送记录**：每次正式发送自动记录（测试邮件不记录）。可按主题、收件人、公司搜索；展开一批可看到发件人、抄送、密送、通用变量、附件（可下载），以及每一封的收件人、主题、结果、是否已存入“已发送”、发送时间；点“查看”可看到当时发出的邮件原文，并可下载原始邮件（`.eml`，可用 Foxmail 打开）。只读，不能修改或删除。
- **备份与恢复**：见下文“备份与换电脑”。

### 3. 签名

填写签名文字，可上传 Logo。写邮件时勾选“附带签名”即自动加在正文末尾（Logo 内嵌在邮件中，对方无需点“显示图片”）。

### 4. 账号设置

填写邮箱地址和密码/授权码，点 **“测试并保存”**（会真实登录一次验证）。

- 常见个人邮箱（QQ、163、126、Gmail、Outlook…）会按域名**自动识别**服务器，并提示授权码在哪里获取。
- 公司邮箱请在“邮箱服务商”中选择（263、腾讯企业邮、阿里企业邮、网易企业邮、Microsoft 365），不确定可问 IT。
- **发送后存入“已发送”**（默认开启，推荐）：每封邮件发出后，自动通过 IMAP 把完全相同的一份（含附件、密送信息）存入邮箱的“已发送”文件夹，在网页版、Foxmail、手机上都能看到，和手动发的邮件一样。“测试并保存”时会同时验证 IMAP 登录并自动找到“已发送”文件夹。
- 暂时连不上服务器时可以选“仍然保存”，等网络正常后再发送。

## 推荐的发送流程

1. 载入模板，或新建邮件 → 添加收件人 → 填写通用变量 → 检查主题、正文、附件
2. 点 **预览**，逐封检查称呼、公司名等变量是否正确
3. 点 **发一封给自己测试**，在自己邮箱里确认实际效果（签名、Logo、附件）
4. 点 **发送** → 核对确认清单 → 确认发送

## 防出错机制

- **先整体校验，再发送**：邮箱格式错误、重复收件人、变量缺失等问题会一次性列出，**有任何问题则一封都不发**。
- **发送前确认清单**：列出每一封的收件人和主题、抄送、附件、是否带签名。
- **发信前先登录**：登录失败不会发出任何邮件。
- **逐封独立**：单封失败不影响其他封；发送结束后可 **“重试失败项”**，只重发失败的那几封。
- **地址被拒识别**：收件人本人的地址被服务器拒收时算作**失败**（即使抄送同事收到了）；只是部分抄送地址被拒时算成功并给出提醒。
- **两层留痕**：邮箱“已发送”文件夹（服务器端，电脑坏了也不丢）＋ 本地“发送记录”（便于搜索和统计）。存入“已发送”失败只会提醒，不影响发送结果，避免误以为没发出而重发。
- **测试模式**：“发一封给自己测试”只发到自己邮箱，不抄送任何人，主题前加“[测试]”。
- **发送间隔 2 秒**：降低被对方服务器判为垃圾邮件的风险。

## 备份与换电脑

在 **资料管理 → 备份与恢复** 中操作：

1. **导出备份**：勾选要导出的内容（默认全部），点“导出备份”，会在项目的 `backups/` 文件夹生成 `邮件助手备份_日期时间.zip`。**请把这个文件拷贝到网盘保存。**
   - 只勾选部分内容（如模板、名单）导出，也可以用来**分享给同事**。
   - **授权码永远不会被导出**；资料包被别人拿到也不会泄露邮箱密码。
   - 只会带上仍在使用的附件（模板、草稿里的附件和签名 Logo），不会带上早已不用的旧上传文件。
2. **恢复 / 换电脑**：在新电脑上打开邮件助手，点“导入其他位置的备份…”，选择网盘里的 `.zip`，勾选要恢复的内容：
   - **合并（推荐）**：保留现有资料，只添加没有的；同名但内容不同的以“名称（导入）”加入，不会覆盖。
   - **替换**：用备份内容覆盖所选项目。
   - 无论哪种方式，**发送记录只增不删**；恢复账号后需在“账号设置”重新输入授权码。
3. **自动保护**：
   - 每天第一次打开邮件助手时自动备份一次；每次恢复前也会自动备份当前资料（恢复错了可用它以“替换”方式撤回）。
   - 自动备份放在 `backups/自动备份/`，保留最近 7 份。它们和电脑在同一块硬盘上，**只能防误操作，防不了电脑损坏**——定期手动导出并拷到网盘仍然必要。

## 数据保存位置

所有资料都在 `userdata/` 文件夹中，备份文件在 `backups/` 文件夹中：

| 文件 | 内容 |
|---|---|
| `account.json` | 发件账号与服务器设置（授权码已加密） |
| `signature.json` | 签名文字与 Logo |
| `draft.json` | 正在编辑的草稿（自动保存） |
| `templates.json` | 邮件模板 |
| `recipient_lists.json` | 收件人名单 |
| `email_groups.json` | 抄送/密送组合 |
| `uploads/` | 上传过的附件与 Logo |
| `history/` | 发送记录：每批一个文件夹，含 `batch.json`（谁、何时、发给谁、结果）、每封邮件原文 `.eml`（不含附件内容）、附件（每批只存一份） |
| `history.jsonl` | 旧版本的简易发送记录（仅保留，不再写入、不在界面显示） |
| `app.log` | 运行日志 |
| `../backups/` | 导出的备份（根目录）、`自动备份/`、`导入的备份/`（从其他位置选择导入的 `.zip`） |

> 授权码使用 Windows 自带加密（DPAPI）保存，**只有本机当前 Windows 用户能解密**。换电脑或换用户后需在账号设置中重新输入。
> `uploads/` 中的文件不会自动清理，可在不需要时手动删除较早的文件夹（注意模板仍引用的附件会失效）。

## 常见问题

**登录失败 / 提示需要授权码**
QQ、163、Gmail 等需要在邮箱网页版开启 SMTP 并生成“授权码”，填授权码而不是登录密码。账号设置页面会提示获取路径。

**263 企业邮箱怎么填**
服务商选 **“263 企业邮箱”** 即可（`smtp.263.net`，端口 **465**，加密 **SSL**）。不要照搬 Foxmail 里的 25 端口，25 端口常被网络封锁。

**提示“无法连接 SMTP 服务器”，并说地址被解析成 198.18.x.x**
说明电脑上的 VPN / 代理软件（TUN 模式）接管了网络，并拦截了发信端口。可以：
- 彻底退出 VPN（托盘图标右键“退出”，并关闭 TUN/服务模式；有些软件会自动重启，请确认已真正退出）；或
- 在 VPN 规则中把邮件服务器（如 `263.net`）设为直连（DIRECT）；或
- 若是公司安全软件拦截，请联系 IT 允许 `python.exe` 发送邮件。

**发送成功但提示“未能存入已发送”**
邮件已经发给对方，只是副本没存进邮箱。常见原因：IMAP 端口被网络拦截、邮箱未开启 IMAP、授权码不支持 IMAP。可在账号设置的“高级设置”中检查 IMAP 服务器（263 为 `imap.263.net`、端口 **143**、加密 **STARTTLS**），点“测试并保存”验证。本地“发送记录”不受影响，仍完整记录。

**页面提示“邮件助手已关闭”**
后台程序已退出（手动退出或长时间无页面而自动退出），重新双击 `邮件助手.pyw` 即可，资料都还在。

**想看详细报错**
查看 `userdata/app.log`，或双击 `调试启动（显示日志窗口）.bat` 以带命令行窗口的方式运行。

## 项目结构

```
邮件助手.pyw                    双击启动（无命令行窗口）
调试启动（显示日志窗口）.bat     带日志窗口启动，排查问题用
userdata/                       个人资料（账号、模板、名单等，见上文）
mailer/
  webapp.py      本地网页服务：只监听 127.0.0.1，带随机令牌防止其他网页调用；单实例、空闲自动退出
  static/        界面：index.html / app.js / app.css
  store.py       资料存取：账号、签名、草稿、模板、名单、组合、上传文件
  secret.py      授权码加密（Windows DPAPI）
  providers.py   常见邮箱的 SMTP / IMAP 服务器预设
  sentbox.py     通过 IMAP 把发出的邮件存入“已发送”（自动识别文件夹，兼容 263 的旧式加密）
  archive.py     本地发送记录（userdata/history/）
  backup.py      备份导出 / 检查 / 恢复（合并或替换）、自动备份
  ---- 核心（与界面无关，可单独复用）----
  service.py     编排：build_mails() 生成并整体校验全部邮件 / send_all() 逐封发送
  recipients.py  收件人表格解析与校验（CSV / Excel）
  template.py    {{变量}} 替换
  body.py        正文加载、文本 ↔ HTML
  signature.py   签名与内嵌图片
  attachments.py 附件收集与大小校验
  builder.py     MIME 邮件组装
  sender.py      SMTP 发送（SSL / STARTTLS）
  sendlog.py     发送记录
  cli.py         命令行版本（可选，见下文）
tests/           自动化测试（含本地假 SMTP 服务器）
jobs/ config/ signatures/   命令行版本的示例任务与配置
```

界面层（`webapp.py`、`static/`、`store.py`）只调用核心层的 `build_mails()` / `send_all()`；更换界面或发送方式时，核心模块无需改动。

## 命令行版本（可选）

供批处理或自动化使用，日常使用图形界面即可。它不读取界面里保存的账号：需先把 `config/smtp.example.toml` 复制为 `config/smtp.toml` 并填写，任务写法参考 `jobs/rfq_demo/job.toml`：

```bash
python -m mailer preview jobs/rfq_demo/job.toml
```

```bash
python -m mailer send jobs/rfq_demo/job.toml --test-to 你的邮箱
```

## 测试

```bash
python -m unittest discover -s tests -v
```

测试使用本地假 SMTP / IMAP 服务器，不会发出真实邮件。覆盖：模板变量、名单解析（CSV/GBK/Excel）、MIME 结构（签名内嵌图、中文附件名）、密送不泄露、收件人/抄送被拒的区分、失败重试、存入“已发送”（XLIST / LIST 标记 / 按名称识别、中文文件夹名、失败只提醒）、发送记录与下载、备份导出与恢复（不含密码、合并改名、防路径穿越、自动备份数量）、账号加密保存、通用变量、名单/组合/模板的保存与重命名、界面接口的安全校验等。
